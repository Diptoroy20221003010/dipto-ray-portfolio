# Dipto Ray's Portfolio

A sleek, modern portfolio website for a graphic designer with a dark purple-to-black gradient background, neon accents, and smooth animations to showcase design skills and projects.

## Features

- **Header & Hero Section:** Navigation bar with Home/Skills/Projects/Education/Contact, prominent name display, and a compelling introduction with social media links and downloadable resume button.
- **Design Tools Section:** Visual display of design software proficiency (Adobe Suite, Figma, Canva, etc.) using styled badge cards with icons.
- **Projects Showcase:** Three featured projects with hover animations, descriptions, and relevant tags to demonstrate design capabilities across branding, social media, and UI design.
- **Education Timeline:** Vertical timeline showing academic achievements and educational background.
- **Contact Section:** User-friendly contact form with supporting illustration and footer with copyright information.

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vite
